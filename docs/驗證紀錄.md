## 執行方式

先完成 README 的安裝、建置、本機 migration 與開發服務啟動，再用 Node 22.13 以上執行：

```powershell
node scripts/verify-api.mjs
```

腳本只允許 loopback Demo，使用 starter 的本機模擬登入。會真的新增及異動虛擬資料，且保留稽核紀錄，請勿用在正式資料環境。
