# 新建專案修改對照

使用者工作目錄原為空白 Git 目錄。從 Sites starter 建立獨立 `nursing-hub` 來源，以下檔案皆為首版完整實作。完整程式位於所列檔案，可直接複製整份；沒有既有使用者程式段落需要局部貼換。

| 修改前 | 修改後完整來源 | 功能 |
| --- | --- | --- |
| starter 佔位頁 | `app/page.tsx`、`app/hub.tsx` | 登入、六個管理分頁與操作表單 |
| starter 預設樣式 | `app/globals.css` | 響應式側欄、總覽、清冊、對話框及人員抽屜 |
| 空白 schema | `db/schema.ts`、`drizzle/0000_previous_mojo.sql` | 七張關聯式資料表 |
| 無種子與資料服務 | `lib/types.ts`、`lib/seed.ts`、`lib/store.ts` | 6 單位／60 人及持久化讀取 |
| 無管理服務 | `app/api/state/route.ts`、`app/api/manage/route.ts` | 登入後管理、驗證、版本衝突與事件交易 |
| 無共用介面 | `lib/api.ts`、`app/api/v1/*/route.ts`、`app/api/openapi/route.ts` | 限定範圍的唯讀 API 與異動同步 |
| starter 預設標題／圖示 | `app/layout.tsx`、`public/favicon.svg` | 中文品牌與語言設定 |
| 無驗證腳本 | `scripts/verify-api.mjs` | 本機 16 項整合檢查 |

`.openai/hosting.json` 登錄本 Site ID，啟用 `DB` D1 binding。金鑰與環境檔不在來源中。`scripts/vite/`、Worker 及建置工具沿用 starter 的 Sites 整合。

公開分享追加：`lib/access.ts` 驗證管理員；`app/page.tsx` 傳入可修改旗標；`app/api/state/route.ts` 分別提供管理資料或固定 Demo；`app/api/manage/route.ts` 在伺服器拒絕非管理員寫入；`lib/seed.ts` 提供固定分享快照。完整對應程式以檔案為準。
